# คู่มือการใช้งาน — LaundryKing (LinenFlow)

คู่มือสำหรับ **เจ้าของกิจการ/ผู้ดูแล (เว็บ)** และ **พนักงานหน้างาน (เครื่องสแกน RFID)**
ส่วนพนักงานเป็น **สองภาษา ไทย/อังกฤษ** (แรงงานที่อ่านอังกฤษกดปุ่ม EN ได้)

> มีฉบับหน้าเว็บ (พิมพ์เป็น PDF ได้) ที่ `docs/user-guide.html`

- **เว็บ:** https://laundryking.senses-iot.com
- **แอปสแกน:** LaundryKing Scanner (Chainway C72) — https://laundryking.senses-iot.com/downloads/LaundryKingScanner.apk

---

## 1. ระบบนี้คืออะไร

LaundryKing ใช้ระบบ **LinenFlow** จัดการผ้าของโรงซักครบวงจร มี 2 ส่วนทำงานร่วมกัน:
- **เว็บแอป** — เจ้าของ/ผู้ดูแลจัดการข้อมูลทั้งหมด (เปิดจากเบราว์เซอร์)
- **แอปเครื่องสแกน (Chainway C72)** — พนักงานยิงป้าย RFID เพื่อรับเข้า/จ่ายออก/ส่งซัก/ตรวจนับ/ลงทะเบียน ทำงานแม้ไม่มีเน็ต

ทั้งเว็บและแอปสลับ **ไทย ⇄ อังกฤษ** ได้

## 2. แนวคิดสำคัญ

**ผ้าเช่า (Rental)** — ผ้าของโรงซัก ปล่อยเช่า คิดค่าเช่าต่อรอบ
**ผ้าลูกค้า (COG)** — ผ้าของลูกค้าเอง โรงซักแค่รับมาซักแล้วคืน ผูกกับลูกค้ารายนั้นถาวร ห้ามปนผ้าเช่า

**สถานะผ้า:** `In Stock` พร้อมใช้ · `Washing` กำลังซัก · `On-Rent` ถูกเช่า
ผ้าแต่ละชิ้นมี **ป้าย RFID** 1 ป้าย เครื่องสแกนอ่านป้ายเพื่อเปลี่ยนสถานะอัตโนมัติ

## 3. เริ่มต้นใช้งาน — ลำดับการตั้งค่า (ผู้ดูแล ทำบนเว็บ)

1. **เข้าสู่ระบบ + เปลี่ยนรหัสผ่าน** (หน้า Account)
2. **เพิ่มประเภทผ้า (Linen Types)** — SKU เช่น "ผ้าเช็ดตัว 70×140 ขาว"
3. **เพิ่มลูกค้า (Customers)**
4. **เพิ่มผู้จัดจำหน่าย (Suppliers) + สต็อกวัสดุ (Stock)** — ถ้าต้องการคุมต้นทุน
5. **ลงทะเบียนผ้า (ติดป้าย RFID)** — บนเว็บ หรือใช้โหมดลงทะเบียนบนเครื่องสแกน (แนะนำสำหรับล็อตใหญ่)
6. **งานประจำวัน** — ใบสั่งงาน, จ่ายออก, รับคืน, การเงิน
7. **ดูรายงาน (Reports)**

> ต้องมีประเภทผ้า/ลูกค้า/ใบสั่งงานในระบบก่อน ตัวเลือกในเครื่องสแกนจึงจะมีให้เลือก (เครื่องดึงมาเก็บอัตโนมัติเมื่อเปิดหน้าเลือกงานตอนต่อเน็ต)

## 4. คู่มือเว็บ (ผู้ดูแล)

เปิด https://laundryking.senses-iot.com → ล็อกอิน เมนูอยู่แถบซ้าย มุมขวาบนมีปุ่มสลับภาษา + สาขา

- **Dashboard** — สรุปงาน/รายได้/ลูกค้า + กิจกรรมล่าสุด (ข้อมูลจริง)
- **ประเภทผ้า (Linen Types)** — สร้าง/แก้ SKU (ชื่อ/รหัส/หมวด/ขนาด/ราคา)
- **ลูกค้า (Customers)** — เพิ่ม/แก้ + คลิกดูรายละเอียด/ประวัติงาน
- **ผู้จัดจำหน่าย (Suppliers)** + **สต็อกวัสดุ (Stock)** — วัสดุสิ้นเปลือง + เตือนของใกล้หมด + รับเข้า/เบิกออก
- **ลงทะเบียนผ้า (Register)** — เลือกประเภท + เจ้าของ (เช่า/COG) แล้วยิง/พิมพ์รหัสป้าย
- **คลังผ้า (Inventory)** — รายการผ้า + สถานะ + กรอง

## 5. งานประจำวัน (เว็บ)

- **ใบสั่งงาน (Job Orders)** — เลือกลูกค้า/บริการ/น้ำหนัก ระบบคิดราคารวมให้ เปลี่ยนสถานะ/ยกเลิกได้
- **รับคืน (Check-in)** — ถูกเช่า → พร้อมใช้ หรือ → กำลังซัก
- **จ่ายออก (Dispatch)** — พร้อมใช้ → ถูกเช่า + พิมพ์ป้ายจัดส่ง
- **การเงิน** — Expenses (บันทึกค่าใช้จ่าย + VAT), Invoices (ใบแจ้งหนี้จากใบสั่งงาน, รับชำระ, ยกเลิก)
- **รายงาน (Reports)** — รายได้/ต้นทุน/กำไร ตามช่วงเวลา

## 6. คู่มือเครื่องสแกน (พนักงาน) — TH / EN

**ติดตั้ง/อัปเดต · Install/Update:** File Manager → Download → แตะ `LaundryKingScanner.apk` → Install (อนุญาต "ติดตั้งจากแหล่งที่ไม่รู้จัก" ครั้งแรก) · หรือโหลดจาก `laundryking.senses-iot.com/downloads/LaundryKingScanner.apk`

**เข้าสู่ระบบ + ภาษา · Login + Language:** เปิดแอป → กด **EN / ไทย** → กรอกอีเมล+รหัส (บัญชีเดียวกับเว็บ) → เข้าสู่ระบบ (แอปจำภาษาไว้)

**งาน 5 อย่าง (แตะปุ่มสีที่หน้า "เลือกงาน") · The 5 tasks:**

| ปุ่ม · Button | ทำอะไร · What | สถานะ · Status |
|---|---|---|
| 📤 จ่ายออก · Dispatch | ผ้าออกไปหาลูกค้า · hand out | → On-Rent (เลือกใบสั่งงานได้) |
| 📥 รับคืน · Return | ผ้ากลับเข้าคลัง · comes back | → In Stock |
| 🧺 ส่งซัก · To wash | รับผ้ามาซัก · take in to wash | → Washing (เลือกลูกค้าได้) |
| 🔢 ตรวจนับ · Stock count | นับผ้า · count only | ไม่เปลี่ยนสถานะ |
| ➕ ลงทะเบียน · Register | ผ้าใหม่ติดป้าย · new tag | เลือกประเภท + เจ้าของ |

**วิธียิงและบันทึก · How to scan & save:**
1. เลือกงาน (แตะปุ่มสี) · Choose a task
2. เลือกช่อง (ประเภท/เจ้าของ/ลูกค้า/ใบสั่งงาน) ถ้ามี · Fill pickers if shown
3. **ดึงไกปืน** ยิงป้าย (หรือ ▶ เริ่มสแกน) — ตัวเลขใหญ่จะเพิ่ม · Pull trigger; the big number counts
4. กดเขียว **✓ บันทึก · Save**
5. ดูผล: ✅ สำเร็จ N · ⚠️ ไม่ผ่าน (บางป้ายมีปัญหา)

**ทำงานไม่มีเน็ต · Offline:** ยิง+บันทึกได้แม้เน็ตหลุด งานเก็บในเครื่อง ("รอส่ง") แล้วส่งเองเมื่อมีเน็ต

## 7. แก้ปัญหาที่พบบ่อย · Troubleshooting

| อาการ | วิธีแก้ |
|---|---|
| ป้ายไม่ผ่าน (rejected) | สถานะไม่ตรงงาน หรือป้ายยังไม่ลงทะเบียน — ตรวจว่าลงทะเบียนแล้ว + เลือกงานถูก |
| ช่องเลือกว่างเปล่า | ยังไม่มีข้อมูล/ยังไม่ sync — สร้างบนเว็บก่อน แล้วเปิดหน้าเลือกงานใหม่ตอนต่อเน็ต |
| อ่าน RFID ไม่ได้ | พิมพ์รหัสป้ายเองได้ที่ช่องด้านล่าง |
| ลืมรหัสผ่าน | ติดต่อผู้ดูแลให้รีเซ็ต |
| ติดตั้งไม่ได้ | เปิดสิทธิ์ "ติดตั้งจากแหล่งที่ไม่รู้จัก" |
