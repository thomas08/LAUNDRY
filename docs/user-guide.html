ส่วนที่ 1ระบบนี้คืออะไร

LaundryKing ใช้ระบบ LinenFlow จัดการผ้าของโรงซักแบบครบวงจร — ตั้งแต่ลงทะเบียนผ้าติดป้าย RFID, รับผ้าเข้า/จ่ายผ้าออก, ใบสั่งงาน, สต็อกวัสดุ, การเงิน ไปจนถึงรายงาน ระบบมี 2 ส่วนที่ทำงานร่วมกัน:

  • เว็บแอป — สำหรับเจ้าของ/ผู้ดูแล ใช้จัดการข้อมูลทั้งหมด เปิดจากคอมพิวเตอร์หรือมือถือผ่านเบราว์เซอร์
  • แอปเครื่องสแกน (Chainway C72) — สำหรับพนักงานหน้างาน ใช้ยิงป้าย RFID เพื่อรับเข้า/จ่ายออก/ส่งซัก/ตรวจนับ/ลงทะเบียน ทำงานแม้ไม่มีเน็ต

รองรับสองภาษา

ทั้งเว็บและแอปสลับ ไทย ⇄ อังกฤษ ได้ พนักงานที่อ่านอังกฤษ (เช่น แรงงานพม่า) กดปุ่ม EN ได้ทันที

ส่วนที่ 2แนวคิดสำคัญ

ผ้าเช่า (Rental) กับ ผ้าลูกค้า (COG)

ผ้าเช่า (Rental)
ผ้าของโรงซักเอง ปล่อยเช่าให้ลูกค้า คิดค่าเช่าต่อรอบ — ลูกค้าผูกกับผ้าเฉพาะตอน "ถูกเช่า"
ผ้าลูกค้า (COG)
ผ้าของลูกค้าเอง (เช่น โรงแรม/โรงพยาบาล) โรงซักแค่รับมาซักแล้วคืน คิดค่าซักต่อรอบ — ผูกกับลูกค้ารายนั้นถาวร และห้ามปนกับผ้าเช่า

สถานะของผ้าแต่ละชิ้น

สถานะไทยความหมาย
In Stockพร้อมใช้อยู่ในคลัง พร้อมจ่าย
Washingกำลังซักรับเข้ามาซัก / อยู่ในกระบวนการ
On-Rentถูกเช่าจ่ายออก/อยู่กับลูกค้า

ผ้าแต่ละชิ้นมี ป้าย RFID (Tag) หนึ่งป้ายต่อชิ้น เครื่องสแกนอ่านป้ายเพื่อเปลี่ยนสถานะให้อัตโนมัติ

ส่วนที่ 3เริ่มต้นใช้งาน — ลำดับการตั้งค่า

ทำครั้งแรกตามลำดับนี้ (เจ้าของ/ผู้ดูแลทำบนเว็บ) เพื่อให้ทั้งเว็บและเครื่องสแกนมีข้อมูลให้เลือก:

  1. เข้าสู่ระบบ + เปลี่ยนรหัสผ่าน — ล็อกอินด้วยบัญชีแอดมิน แล้วไปหน้า Account ตั้งรหัสผ่านใหม่ของคุณเอง
  2. เพิ่มประเภทผ้า (Linen Types) — สร้าง SKU เช่น "ผ้าเช็ดตัว 70×140 ขาว", "ผ้าปูเตียง King" พร้อมหมวด/ขนาด/ราคา
  3. เพิ่มลูกค้า (Customers) — โรงแรม/โรงพยาบาล/ร้าน/ลูกค้าทั่วไป
  4. เพิ่มผู้จัดจำหน่าย (Suppliers) และ สต็อกวัสดุ (Stock) — น้ำยา/บรรจุภัณฑ์ (ถ้าต้องการคุมต้นทุน)
  5. ลงทะเบียนผ้า (ติดป้าย RFID) — ทำบนเว็บหน้า "ลงทะเบียนผ้า" หรือใช้ โหมดลงทะเบียนบนเครื่องสแกน (แนะนำสำหรับล็อตใหญ่)
  6. เริ่มงานประจำวัน — สร้างใบสั่งงาน, จ่ายออก, รับคืน, บันทึกค่าใช้จ่าย/ใบแจ้งหนี้
  7. ดูรายงาน — รายได้/ต้นทุน/งาน ที่หน้า Reports

เคล็ดลับ

ต้องมี ประเภทผ้า / ลูกค้า / ใบสั่งงาน ในระบบก่อน ตัวเลือก (dropdown) ในเครื่องสแกนถึงจะมีให้เลือก เครื่องจะดึงข้อมูลมาเก็บไว้อัตโนมัติเมื่อเปิดหน้าเลือกงานตอนต่อเน็ต

Dashboard (หน้าแรก)

สรุปภาพรวม: จำนวนงาน, งานที่กำลังทำ, รายได้เดือนนี้, จำนวนลูกค้า และกิจกรรมล่าสุด — ตัวเลขมาจากข้อมูลจริงในระบบ

ประเภทผ้า · Linen Types

คลัง "แม่แบบ" ของผ้า (SKU) กด Add เพื่อสร้าง กรอกชื่อ/รหัส/หมวด/ขนาด/สี/น้ำหนัก/ราคา แก้ไขหรือปิดใช้งานได้ — ใช้เป็นตัวเลือกตอนลงทะเบียนผ้า

ลูกค้า · Customers

เพิ่ม/แก้ไขลูกค้า (ชื่อ, ประเภท, ผู้ติดต่อ, ที่อยู่, เครดิต) คลิกชื่อลูกค้าเพื่อดูรายละเอียด + ประวัติใบสั่งงาน

ผู้จัดจำหน่าย · Suppliers & สต็อกวัสดุ · Stock

Suppliers = ร้านที่ซื้อของ · Stock = วัสดุสิ้นเปลือง (น้ำยา/บรรจุภัณฑ์) มีระบบเตือนของใกล้หมด และบันทึกรับเข้า/เบิกออกผ่านปุ่มเคลื่อนไหวสต็อก

ลงทะเบียนผ้า · Register Linen

ผูกป้าย RFID เข้ากับผ้า: เลือกประเภทผ้า + เจ้าของ (เช่า/COG) แล้วยิง/พิมพ์รหัสป้าย — ทำได้ทั้งทีละชิ้นและหลายชิ้น (เหมาะกับล็อตเล็ก; ล็อตใหญ่ใช้เครื่องสแกน)

คลังผ้า · Inventory

ดูรายการผ้าทั้งหมดพร้อมสถานะ (พร้อมใช้/กำลังซัก/ถูกเช่า) และเจ้าของ กรองตามสถานะ/ประเภทเจ้าของได้

ส่วนที่ 5งานประจำวัน (เว็บ)

ใบสั่งงาน · Job Orders

สร้างงานซัก: เลือกลูกค้า, ประเภทบริการ, น้ำหนัก/ราคา ระบบคิดราคารวมให้ เปลี่ยนสถานะงานและยกเลิกได้ในหน้าเดียว

รับคืน · Check-in / จ่ายออก · Dispatch

ปรับสถานะผ้าจริง: Check-in รับผ้าคืน (ถูกเช่า → พร้อมใช้ หรือ → กำลังซัก) · Dispatch จ่ายผ้าออกให้ลูกค้า (พร้อมใช้ → ถูกเช่า) + พิมพ์ป้ายจัดส่ง หน้าเหล่านี้ทำงานด้วยการยิง/พิมพ์รหัสป้าย เช่นเดียวกับเครื่องสแกน

การเงิน · Expenses / Invoices

Expenses บันทึกค่าใช้จ่าย (คิด VAT ให้) · Invoices ออกใบแจ้งหนี้จากใบสั่งงาน, รับชำระบางส่วน, เปลี่ยนสถานะ, ยกเลิก

รายงาน · Reports

สรุปรายได้/ต้นทุน/กำไร, ยอดตามบริการ, ต้นทุนตามหมวด เลือกช่วงเวลาได้ (วัน/สัปดาห์/เดือน/ไตรมาส/ปี)

วิธียิงและบันทึก — How to scan & save

ไทย
  1. เลือกงาน (แตะปุ่มสี)
  2. ถ้ามีช่องให้เลือก (ประเภทผ้า/เจ้าของ/ลูกค้า/ใบสั่งงาน) เลือกให้ครบ
  3. ดึงไกปืน บนเครื่องเพื่อยิงป้าย (หรือกดปุ่ม ▶ เริ่มสแกน) — ตัวเลขใหญ่ จะเพิ่มตามจำนวนที่ยิงได้
  4. กดปุ่มเขียว ✓ บันทึก
  5. ดูผล: ✅ สำเร็จ N ชิ้น = เรียบร้อย · ⚠️ ไม่ผ่าน = มีบางป้ายมีปัญหา
English
  1. Choose a task (tap a colored button)
  2. If pickers appear (type / owner / customer / job order), select them
  3. Pull the trigger to read tags (or tap ▶ Start scan) — the big number counts each tag read
  4. Tap the green ✓ Save
  5. Read the result: ✅ N saved = done · ⚠️ rejected = some tags had a problem

ทำงานไม่มีเน็ต · Works offline

ยิงและกดบันทึกได้แม้เน็ตหลุด — งานจะถูกเก็บไว้ในเครื่อง (ขึ้น "รอส่ง") แล้วส่งเองอัตโนมัติเมื่อกลับมามีเน็ต ไม่ต้องกลัวข้อมูลหาย.
Scanning & saving work without internet — items are queued ("Pending") and upload automatically when back online.

ส่วนที่ 7 · Part 7แก้ปัญหาที่พบบ่อย · Troubleshooting

อาการ · Symptomวิธีแก้ · Fix
ป้าย ไม่ผ่าน (rejected) ตอนบันทึกสถานะไม่ตรงกับงาน (เช่น จ่ายออกผ้าที่ยังไม่ได้ลงทะเบียน) หรือป้ายยังไม่มีในระบบ — ตรวจว่าลงทะเบียนผ้าแล้ว และเลือกงานให้ถูก · Wrong status for the task, or the tag was never registered.
ช่องเลือก ว่างเปล่า (ไม่มีประเภทผ้า/ลูกค้า)ยังไม่มีข้อมูลในระบบ หรือเครื่องยังไม่ได้ sync — เข้าเว็บสร้างข้อมูลก่อน แล้วเปิดหน้า "เลือกงาน" ใหม่ตอนต่อเน็ต · Create data on the web first, then reopen the app online.
อ่าน RFID ไม่ได้ / เครื่องอ่านไม่เจอแอปจะขึ้น "พิมพ์แท็กด้านล่าง" — ยังพิมพ์รหัสป้ายเองได้ · You can still type tags manually.
ลืมรหัสผ่านติดต่อผู้ดูแล/เจ้าของให้รีเซ็ตให้ · Contact the admin/owner to reset.
ติดตั้งแอปไม่ได้เปิดสิทธิ์ "ติดตั้งจากแหล่งที่ไม่รู้จัก" ให้ File Manager/เบราว์เซอร์ · Allow "install from unknown sources".
เข้าเว็บไม่ได้ตรวจอินเทอร์เน็ต และพิมพ์ที่อยู่ให้ครบ https://laundryking.senses-iot.com
